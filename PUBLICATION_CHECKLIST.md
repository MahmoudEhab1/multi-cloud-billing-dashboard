# Pre-publication checklist

- [ ] Rights holder approved public source publication.
- [ ] Fresh Git history; no production history imported.
- [ ] `.env`, databases, caches, logs, keys, browser state, backups, and archives absent.
- [ ] All customer/company identifiers replaced with synthetic names.
- [ ] All screenshots use synthetic data only.
- [ ] Secret scan is clean.
- [ ] Manual search for emails, domains, IP addresses, account IDs, invoice IDs, chat IDs, and internal paths is clean.
- [ ] Third-party dependency licenses reviewed.
- [ ] GitHub secret scanning and push protection enabled.
- [ ] License approved by rights holder.
